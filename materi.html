Learning notes

Memahami teknologi, dari dasar.

Catatan konsep yang saya pelajari sebagai bagian dari perjalanan memahami website dan infrastruktur TI.

01 / WEB

Web server

Perangkat lunak atau sistem yang menerima permintaan HTTP dari browser dan mengirimkan respons, seperti halaman website atau aset lainnya.

02 / NETWORK

IP address

Alamat logis yang digunakan untuk mengidentifikasi antarmuka perangkat pada jaringan dan membantu pengiriman data ke tujuan.

03 / DOMAIN

DNS

Sistem yang membantu menerjemahkan nama domain menjadi informasi yang diperlukan, misalnya alamat IP, untuk menemukan layanan di internet.

04 / ACCESS

Web browser

Aplikasi yang meminta sumber daya dari server dan menampilkan halaman web kepada pengguna.

05 / DEPLOYMENT

Hosting

Layanan yang menyediakan sumber daya agar file dan aplikasi website dapat diakses melalui jaringan.

06 / PRACTICE

HTML, CSS, JavaScript

HTML menyusun konten, CSS mengatur presentasi visual, dan JavaScript menambahkan perilaku interaktif pada halaman web.
